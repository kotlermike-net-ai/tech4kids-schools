Vibe Coding

מה בנו התלמידים

Vibe Coding היא דרך חדשה לפתח תוכנה, שנולדה רק בשנים האחרונות. במקום לכתוב קוד, מתארים לבינה המלאכותית במילים רגילות מה רוצים לבנות, והיא כותבת את הקוד. היום מי שיודע להסביר רעיון בבירור יכול לבנות משחק או אפליקציה. התלמידים עבדו כך ובנו כמה משחקים, ביניהם קליקרים, משחק פסנתר ומשחק כדור שקופץ בין סלים.

  • תכנות

    בנו אויבים, ניקוד, חיים וצלילים, וחיברו הרבה בלוקים של קוד למשחק אחד שעובד.

    חילקו משחק גדול לחלקים קטנים ובנו אותם אחד אחרי השני, מרעיון ועד משחק גמור.

  • חשיבה לוגית

    הפכו חוקי משחק לתנאים ולסדר פעולות.

    עיצבו את הדמויות והאויבים.

  • קבלת החלטות

    כל תלמיד בחר איך המשחק ייראה ואיך יתנהג.

  • פלטפורמות

    אותו משחק רץ במחשב ובנייד, ואפשר להוריד אותו.

  • מילים שהופכות לקוד

    הבינו שה-AI מתרגם תיאור במילים לקוד שהמחשב מריץ.
